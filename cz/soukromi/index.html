Soukromí

Zadané údaje se zpracovávají v prohlížeči. Tento web nepoužívá analytiku třetích stran, reklamní skripty ani externě načítaná písma.

Uložené oblíbené kalkulačky

Když si uložíš kalkulačku, její identifikátor se uloží do místního úložiště prohlížeče. Oblíbené tak zůstanou dostupné na tomto zařízení. Opětovným kliknutím na uložení kalkulačku odebereš. Zadané hodnoty se spolu s oblíbenými neukládají.

Sdílené odkazy

Funkce „Sdílet údaje“ vloží aktuální hodnoty do adresy URL a zkopíruje ji do schránky. Každý, kdo má odkaz, si může údaje přečíst. URL se může uložit do historie prohlížeče a hostingových protokolů. Nesdílej citlivé osobní, zdravotní ani finanční údaje. Porovnání variant zůstává pouze v paměti stránky a po jejím obnovení zmizí.

Hosting

Provozovatel hostingu může při zobrazení webu zpracovávat technické údaje, například IP adresu, čas a požadovanou URL. Samotný výpočet zadané hodnoty na server neposílá; otevřením sdíleného odkazu se však URL provozovateli hostingu odešle.
