How this calculator works

Operations run in the order you press them, just like a basic desk calculator: 2 + 3 × 4 gives 20. Use the scientific calculator for expressions with order of operations and parentheses.

Enter a number, choose an operation, enter the next number and press equals. Press equals again to repeat the last operation.

Percentages and memory

For 200 + 10%, the percentage is 10% of 200, giving 220. For 200 × 10%, the percentage becomes 0.1, giving 20. M+ adds the displayed number to memory; MR recalls it and MC clears it.

Keyboard shortcuts

Use number keys and + − * /. Enter calculates, Backspace removes a digit, Escape clears the calculator and Delete clears the current entry. Focus the calculator first; typing in a search field stays in that field.

Results use floating-point arithmetic and are rounded for display. This is a practical everyday calculator rather than an exact symbolic or accounting tool.
