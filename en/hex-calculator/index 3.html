How to use this calculator

  1. Enter first integer, operation, second integer.
  2. Select Calculate to see the answer and its breakdown.
  3. Keep a scenario, change an input and compare the results.

Use consistent units and check the assumptions below before applying the result.

How hex is calculated

The operands are parsed in base 16, the chosen integer operation is performed, and the result is converted back to uppercase hexadecimal. Division returns an integer quotient and remainder. 0x2A + 0x10 = 0x3A, because 42 + 16 = 58 in decimal.

Parse base-16 integers, perform the selected integer operation, convert result to base 16.
A worked example

0x2A + 0x10 = 0x3A, because 42 + 16 = 58 in decimal.

Assumptions & useful context

The result depends on the values you enter and the method described above. Displayed numbers may be rounded; calculations use the unrounded values. Check that this model matches your situation before relying on it.

Frequently asked questions

Are lowercase letters accepted?

Yes; hexadecimal input is case-insensitive.

What does division do with a remainder?

It reports the integer quotient and remainder rather than a rounded decimal.
